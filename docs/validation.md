## EDA 合成样例摘要

小样例包含 6 行、4 列，CSV/TSV 与 JSON 表示对应的合成记录；结果范围如下：

- CSV/TSV：1 条额外完全重复行、2 个缺失单元格。
- 数值字段：4 个有效数值、1 个非数字值、1 个缺失；有效值之和 1050、均值 262.5、中位数 20、最小值 10、最大值 1000。
- 分组缺失审计与异常敏感性得到预期结果；独立组求和核对不属于上游原生组求和能力。
- JSON：严格解析并核对数组长度与对象字段数；不宣称与表格相同的原生统计能力。
- 重复键 JSON、不规则 CSV、覆盖已有输出、覆盖源 JSON 四类请求均非零退出，源文件与已有输出字节不变。

这是维护者报告的有限本地结果；本导航仓库没有发布完整测试代码、原始审计日志或可独立重放的完整测试包，因此不声称读者可以仅凭本仓库复现全部 41 项检查。没有使用这些结果认证大文件、全部越界方式、可选科学格式或第三方服务。
