# 验证状态与证据范围

32 项资源的推荐等级与验证等级分开；本页不认证安装安全、全部格式保真或跨客户端可用。

## 等级与证据类别

| 范围 | 可以说明什么 | 不代表什么 |
|---|---|---|
| E1：静态格式与内容 | 记录 Frontmatter、资源、代码与许可的已读范围 | 脚本/依赖/客户端运行成功 |
| E2：上游使用示例 | 代码前后对照、命令或工作流示例存在 | 已执行示例或达到宣传效果 |
| E2：上游测试源码 | 具体断言、失败路径及检查对象可查 | 测试已经运行或通过 |
| E2：上游评估设计 | 输入、场景、grader 或评价判据存在 | 模型/客户端已通过评估 |
| E2：可核实成功记录 | 指定版本的 run/job/step 结果及范围 | 所有格式、平台或完整 Skill 通过 |
| E3：本地功能 | 指定版本、环境、输入及实际结果核对 | 其他版本、场景自动成立 |
| E4：客户端端到端 | 指定客户端、工具链与任务的真实调用结果 | 其他客户端自动兼容 |

维护者说明中的“已验证”、生产用途宣传、测试文件名或演示图片不能自动成为成功记录；第三方案例须能核对主体、版本、场景和结果。

## EDA 合成样例摘要

小样例包含 6 行、4 列，CSV/TSV 与 JSON 表示对应的合成记录；结果范围如下：

- CSV/TSV：1 条额外完全重复行、2 个缺失单元格。
- 数值字段：4 个有效数值、1 个非数字值、1 个缺失；有效值之和 1050、均值 262.5、中位数 20、最小值 10、最大值 1000。
- 分组缺失审计与异常敏感性得到预期结果；独立组求和核对不属于上游原生组求和能力。
- JSON：严格解析并核对数组长度与对象字段数；不宣称与表格相同的原生统计能力。
- 重复键 JSON、不规则 CSV、覆盖已有输出、覆盖源 JSON 四类请求均非零退出，源文件与已有输出字节不变。

这是维护者报告的有限本地结果；本导航仓库没有发布完整测试代码、原始审计日志或可独立重放的完整测试包，因此不声称读者可以仅凭本仓库复现全部 41 项检查。没有使用这些结果认证大文件、全部越界方式、可选科学格式或第三方服务。

## OfficeCLI 上游成功记录的边界

[发行构建 run 38242814096](https://github.com/iOfficeAI/OfficeCLI/actions/runs/38242814096)，Commit `b65272a18aef891941451705ff93e8a287f3eb72`，记录 linux-x64、osx-arm64、win-x64 的 `Smoke test - create document` 为 success；其他平台此步骤为 skipped。步骤只创建/添加/读取/关闭 DOCX，没有版式金标准或独立公式数值核对。

因此可写“这些上游 CI 步骤有成功记录”，不能写“OfficeCLI 三个 Skill 测试通过”“Excel/PPT 已验证”或“全部平台稳定”。目录维护者未执行这些测试、未独立核对其产物，且已审源与发行实现存在差异。

Skill parity 的成功记录仅比较 umbrella 文件，不证明三个格式功能。代码扫描 workflow 的成功也不是文档功能测试。Anthropic 专有条目只作受限参考，没有本目录确认的运行结果。

## 如何增加或变更证据

新增证据写清：原始来源、完整版本、材料类型、执行者/环境、样例与预期、实际结果、失败和未覆盖范围。只有有结果的记录才使用“通过”；仅解析语法或命令退出 0 不能证明实际值/版式正确。不发布凭据、业务数据、私人路径或原始审计缓存。

发现工具配对、许可、依赖或安全结论冲突时暂停对应采用建议，保留旧基线并定向复核。Playwright 配对、MarkItDown 转换器、图表字体、MCP SDK/API、GitHub 权限等原有限制继续适用。
