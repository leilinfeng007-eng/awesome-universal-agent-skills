# 获取、安装、更新与回滚

这是手动单项方案，不是安装脚本。没有批量安装、浮动 latest 命令或默认管理器。使用前先阅读所选条目的依赖、许可和采用门槛。

## 1. 获取固定来源

1. 在 catalog.json 找到 repository、directory、完整 commit 与许可证链接。
2. 从该 Commit 的目录获取完整单项及必要资源、LICENSE/NOTICE；可以使用固定 Commit 的归档后只提取目标目录，或按上游公开 API 定向取文件。
3. 不执行仓库 setup/bootstrap，不安装整个合集，不只复制 SKILL.md；核对资源引用与文件哈希。
4. 将固定源码保存在自己选择的独立资源目录。例如相对结构 `skill-sources/<owner-repo>/<commit>/<skill>/`，不将下载源混入项目正式数据。

本仓库不分发源码、安装环境或锁定的依赖包。Skill 的 Commit、底层工具版本与传递依赖是三个不同层次。

## 2. 准备最小环境

- EDA 只用标准库核心，不为可选格式安装整个科学环境。
- MarkItDown 只选必要 extras；包装与底层库分别固定，不装 all。
- Matplotlib 附带脚本需要 NumPy/SciPy 等，依赖锁尚不完整；优先核已有环境，静态图可选择 Agg。savefig 前确保输出不会覆盖已有文件。
- Playwright 的当前审阅基线尚未形成已验证的 Skill/CLI 配套组合，先完成配套审阅，不能直接照抄安装。
- MCP 指南中的 main/最新 SDK/Inspector 示例不能当作固定部署方案；SDK 许可和 API 权限另核。
- PDF 工具按具体任务选择。指南中的系统包管理示例不是必须操作，也不是自动安装授权。
- 参考资源已有等效能力时直接复用，不增加重复入口。

## 3. 创建所需项目入口

按[客户端指南](clients.md)选择原生项目目录。可链接到固定核心的客户端先确认链接与资源定位；必须导入者使用包含必要资源的固定副本。不强行统一所有客户端路径。

**同名目标已存在就停止并比较差异**，不要覆盖、合并或让安装器接管。保留原入口、版本和权限。不修改无关 Skill、认证信息或全局配置。

## 4. 必要验证

使用合成样例核实际值、错误诊断、退出码、源文件哈希和输出保护；只声明已完成的检查范围。格式通过不等于执行通过，也不要求为了入库在每个客户端启动模型。

EDA已有的维护者结果只覆盖小型标准库核心，不取代你自己选择的新版本、新格式或新权限边界的检查。文本型 Skill 的遵守度也不能由静态检查证明。

## 5. 更新与单项回滚

- 只有实际需求、故障或可靠公告才考虑更新，先审上游差异、许可、资源与必要依赖。
- 新版本放独立目录，保留旧 Commit、许可、哈希、入口与已知样例；不修改旧快照来冒充新版本。
- 变更前只备份将受影响的单项链接/副本、相关配置键与版本记录，不复制凭据或整个用户配置。
- 回滚只撤回本次新建入口或恢复旧入口；已被其他项目使用的共享源码不要删除。
- 专属环境/浏览器 profile/测试服务仅清理本次创建的内容；不清空 Skill 根、全局缓存、登录或系统配置。
- 输入数据与正式项目代码独立于 Skill 入口，不能借回滚资源删除它们。
