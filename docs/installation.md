# 获取、采用条件与单项回滚

这是手动选择指南，不是安装器或执行授权。收录不代表应安装全部资源，也不代表默认上游 setup 安全。本仓库不运行远程脚本、不批量安装、不自动更新或刷新任何客户端 Skill。

## 0. 先区分能做什么

在 catalog.json 检查 recommendation、navigation_scope、license、adoption_gate 和 validation。

**标为 restricted_reference 的 Anthropic DOCX/XLSX/PPTX：只读本项目原创介绍，访问原始官方链接和许可说明。不要按本页其他步骤提取、复制、安装、导入、改编、执行或再分发这些材料。** 实际使用资格由读者适用的 Anthropic 服务合同及目录附加条款决定，本目录不作授权推定，也不提供外部执行路线。

其他条目的许可、依赖、网络/写入权限和工具配对也必须先满足；未知就保留未知，不用导航推荐替代采用决策。比较路径见[同类选择](comparisons.md)。

## 1. 对允许获取的材料固定来源

1. 查原始 repository、directory、完整 commit 及许可证，不以同名条目或合集简介代替。
2. 在明确允许的范围内，仅获取目标 Skill 和必要资源及许可/NOTICE；不运行 setup/bootstrap，不安装整个合集，不只复制入口而丢失资源。
3. 保留独立版本目录及来源/文件哈希。Skill Commit、工具版本、依赖锁和实际执行产物是不同层次，不把候选 Runtime 写成配对已通过。
4. 不向公开项目提交下载的第三方源码、脚本、模板、字体、资产或私人配置；本仓库只维护导航与原创说明。

Vercel 两项本体和根 README 明示 MIT，但没有随附完整许可证正文；获取/改编/分发前仍需核清通知与覆盖范围，不能把第三方片段、引用或外链内容一概归为 MIT。本项目不提供再分发包。

## 2. 按任务准备最小环境

- EDA：只用已说明的标准库核心，不为可选格式引入整套科研环境。
- Notebook：脚手架与执行内核分开；明确输出路径，已有文件不自动 force；不执行不可信单元。
- MarkItDown：包装和底层库分别固定，仅选所需 extras，不装 all；数据提取不等于原生 Office 编辑。
- PDF/Matplotlib：按需选库、渲染器和字体，图像输出保护另核；现有依赖/运行限制保留。
- Playwright：当前基线尚未形成已验证的 Skill/CLI 配对，不直接照抄安装；浏览器 profile 与项目权限独立。
- MCP/Agent Architecture：SDK/API 权限和实现任务另获授权；指南、架构交付不是现成服务或部署许可。
- CodeQL：先核工具使用资格与查询包许可/版本；构建会执行项目代码，只对授权目标在独立受控环境操作，不自动补装 Homebrew、Rosetta 或工具链。
- 供应链审计：先确认包名/版本等依赖元数据可向 OSV、注册表、GitHub 等外发；缺数据不表示安全，不把该工具当许可证合规审计。
- Gradio/论文：服务启动、分享、远程模型与论文写端点分开授权；不默认公开页面、上传材料或索取令牌。

## 3. OfficeCLI 的条件性采用方案

OfficeCLI DOCX/XLSX/PPTX 是专项导航，不执行其默认安装流程。未来明确选择采用时，至少满足：

- 直接从 [v1.0.157 固定发行](https://github.com/iOfficeAI/OfficeCLI/releases/tag/v1.0.157)选正确平台资产，核对实际字节、来源与 digest/SHA256SUMS；本目录仅核对过发行元数据，没有下载验证二进制、签名或功能。
- 自管独立工具位置、用完整路径调用，不修改 PATH、全局配置或登录；不调用 install、skills install、MCP 安装和更新入口，不执行 curl|bash / PowerShell 远程脚本。
- **首次及每次调用均需进程级 OFFICECLI_NO_AUTO_INSTALL=1 与 OFFICECLI_SKIP_UPDATE=1。** 静态实现分别在安装/更新路径提前返回。不能仅设置 autoUpdate=false：版本变化触发的已安装 Skill 刷新发生在该配置判断之前。不要为了设置它而先运行未受控 CLI。
- 只使用明确选定的固定 Skill/内嵌资源，不在客户端导入时默认接管已有入口；load_skill 的已审路径读取二进制嵌入资源，不是该路径每次从 main 下载规则，但应记录实际导出版本。
- 审查日志、缓存、临时文件和驻留进程范围；用文档副本验证、写新输出。进程变量并不证明所有副作用消失；单改 HOME 也不等于完整隔离。

Skill 源 Commit `fb98e593612dee2cec36847666671dba502e60aa` 的版本字段是 1.0.157；发行标签指向 `b65272a18aef891941451705ff93e8a287f3eb72`。三个目标 Skill 和关键控制文件 blob 一致，但源提交比发行多 5 个提交、11 个 Word/PPT 实现文件变化。不得说完整源码一致、二进制可复现或复杂格式保真已通过；详见[Office 比较](comparisons.md#office)。

这些是静态方案与采用门槛，本仓库没有自动执行它们，也没有测试三个格式的完整工作流。捆绑 .NET/Open XML 等许可与字体/素材要求另核；运行自包含发行不等于需要安装整个 SDK，也不等于没有依赖。

## 4. 项目入口和名称适配

确认所选材料可合法采用后，再按[客户端机制](clients.md)选择需要的项目入口。链接到固定核心或使用受控副本，都要确保资源和工具可见；不强行统一所有产品目录。

**同名目标已存在就停止并比较差异**，不覆盖、合并或交给安装器接管，不动其他 Skill、认证与全局配置。Vercel 的落地目录可用 name 值，保留原始路径元数据，不修改上游入口；具体规则和错误链接替代路径见[React 比较](comparisons.md#react)。

## 5. 采用后的验证与回滚

若另获运行授权，用合成输入检查实际结果、错误、覆盖保护和源文件不变；版式需渲染/目标查看器检查，不能只凭退出码或静态格式通过。既有 EDA 小样例不认证新版本/大文件/可选格式，也不要求为导航逐个客户端启动模型。

新旧版本分目录保存；备份即将影响的单项入口、版本、许可、哈希及必要配置键，不复制凭据。只有实际需求、故障或可靠公告才考虑更新，先审具体差异，不追浮动 latest。

回滚只撤回本次新建入口或恢复旧入口；不要删除共享资源、业务输入、正式代码或他人输出。浏览器 profile/测试服务只清理本次创建的内容，不清空 Skill 根、全局缓存、插件或客户端登录。受限参考条目不进入安装/回滚流程。
